# Types

The `/types` subpath re-exports the pure TypeScript types used across `@zanix/utils` — no runtime values, no functions, just type-only declarations meant to type your own code against the library's public surface (decorator options, logger shapes, error shapes, encryption/masking options, the Zanix project/folder model, and more).

```ts
import type {
  LoggerBase,
  ValidationOptions,
  ZanixFolderTree,
} from 'jsr:@zanix/utils@[version]/types'
```

Because these are types rather than functions, this page is organized as reference tables by category rather than runnable examples: each table shows the type's real signature (trimmed when very long), its description, and a real consumer inside `@zanix/utils` so you can see where the shape actually comes from.

## Validator types

Types that back the decorator-based validation system exposed from `@zanix/utils/validator` (`BaseRTO` and the `Is*`/`Max*`/`Min*`/`ArrayLength`/`ValidateNested`/`Expose` decorators).

| Type name                        | Definition                                                                                                                                                          | Description                                                                                                                               | Used by                                                                                                                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RtoTypes`                       | `{ Body?: new (...args) => B; Params?: new (...args) => P; Search?: new (...args) => S }`                                                                           | Defines the types for request data transfer objects (RTOs); structures the body, route params and query-string parts of an HTTP request.  | Typing helper for RTO-based route/handler definitions (e.g. in `@zanix/server`); not consumed directly inside this package.                                             |
| `ValidationConstraints`          | `type ValidationConstraints<T> = T`                                                                                                                                 | Represents the subject of validation — an identity type, since validations may apply to different data structures.                        | Used by `ValidationDecorator` as the type of its `validation` argument.                                                                                                 |
| `ValidationDecorator`            | `T extends undefined ? (options?: Opts) => ValidationDecoratorDefinition : (validation: ValidationConstraints<T>, options?: Opts) => ValidationDecoratorDefinition` | Type definition for a validation decorator function: a function that modifies a property accessor to enforce validation rules.            | Used by `Match`, `MaxNumber`, `MinNumber`, `MaxDate`, `MinDate`, `IsDate`, `IsString`, `IsEmail`, `IsNumberString`, `IsBooleanString`, `ArrayLength`, `ValidateNested`. |
| `ValidationDecoratorDefinition`  | `(value: { set(this, value): void }, context: ClassAccessorDecoratorContext) => ClassAccessorDecoratorResult<any, any>`                                             | Defines the structure of a validation decorator applied to a class accessor.                                                              | Return type of `Match`, `IsEmail`, `IsNumberString`, `ValidateNested`, `IsEnum`, and every other validation decorator.                                                  |
| `ValidationError`                | `{ target: object; property: string; value: any; plainValue?: any; constraints: string[]; children?: ValidationError[] }`                                           | Represents an error that occurs during validation.                                                                                        | Used by `classValidation`, `validate`, `ValidateNested`, and the internal validation metadata/accessors modules.                                                        |
| `ValidationFunction`             | `(this: T, val: any, property: string) => Promise<boolean> \| boolean`                                                                                              | Defines the function signature for validation logic: receives a value and returns (or resolves to) a boolean.                             | Used by `defineValidationDecorator`, `ValidateNested`, and the generic decorator utilities.                                                                             |
| `ValidationMessage`              | `(property: string, value: any, target?: any) => string`                                                                                                            | Callback function type for the validation message processor.                                                                              | Used by `ValidationOptions.message`, consumed by `ValidateNested` and the accessor/expose definitions.                                                                  |
| `ValidationOptions`              | `{ message?: string \| ValidationMessage; each?: boolean; optional?: boolean; expose?: boolean; transform?: (value?: string) => any }`                              | Options for validation decorators; allows customization of validation messages, per-item (`each`) behavior, and value transformation.     | Used by `ValidateNested`, `ArrayLength`, `IsEnum`, and the generic decorator utilities.                                                                                 |
| `DefaultTransformValidationOpts` | `Omit<ValidationOptions, 'transform' \| 'expose'> & { transform?: boolean }`                                                                                        | Validation options for decorators with a boolean-only `transform` flag (auto-convert the value to the target type unless set to `false`). | Used by `MinDate`, `MaxDate`, `IsDate`, `MinNumber`, `MaxNumber`.                                                                                                       |
| `EnumType`                       | `Record<string, unknown> \| unknown[]`                                                                                                                              | An enum-like object, or an array of literal values treated as an enum.                                                                    | Used by `IsEnum` (and its internal `isEnum`/`isEnumArray` helpers).                                                                                                     |

## Logger types

Types describing the logging pipeline exposed from `@zanix/utils/logger` (`Logger` and the global `logger` instance).

| Type name                 | Definition                                                                                                                          | Description                                                                                                                              | Used by                                                                                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `BaseFormattedLog`        | `Record<string, unknown>`                                                                                                           | The base formatted log object shape.                                                                                                     | Constrains the `T` generic of `LoggerFormatter`/`Formatter`; base for `DefaultFormattedLog`.                                                 |
| `DefaultFormattedLog`     | `{ id: string; timestamp: string; level: LoggerMethods; message: string; data: unknown[]; context: { processId: number \| null } }` | The default formatted log object produced by the built-in formatter.                                                                     | Used by the internal `defaultFormatter` (in `modules/logger/defaults/formatter.ts`), which backs `LoggerBase`'s default `storage.formatter`. |
| `DefaultLogger`           | `typeof Logger['prototype']`                                                                                                        | The default `Logger` instance shape exposed via `Znx.logger`.                                                                            | Used by `ZanixGlobal.logger` / `ZanixGlobal['Znx']['logger']`; documented as the shape of the global `logger` from `@zanix/utils/logger`.    |
| `DefaultResponse`         | `Promise<void>`                                                                                                                     | The log method's default return type.                                                                                                    | Default value for the `Return` generic of `LoggerBase` (`Logger<Return = DefaultResponse>`).                                                 |
| `LoggerBase`              | `class Logger<Return = DefaultResponse> { debug, error, info, success, warn }`                                                      | The internal `Logger` base class that the public `Logger` (from `@zanix/utils/logger`) extends, so it can be nameable in generated docs. | Extended by the exported `Logger` class in `@zanix/utils/logger`.                                                                            |
| `LoggerData`              | `Method extends 'success' ? string : [message: string, ...data: [...Parameters<ConsoleInfo<Method>>, noSave?: 'noSave']]`           | The data accepted by a logger call, shaped per logging method.                                                                           | Used by every `Logger` method (`debug`, `error`, `info`, `success`, `warn`) and by `LoggerFormatter`.                                        |
| `LoggerFormatter`         | `(level: LoggerMethods, log: LoggerData) => T`                                                                                      | Formatter function type used to shape a log entry before it is saved.                                                                    | Used by `Logger`'s internal `#formatter` field and the `storage.formatter` option.                                                           |
| `LoggerMethods`           | `'info' \| 'error' \| 'warn' \| 'debug' \| 'success'`                                                                               | The logger's available method names.                                                                                                     | Used by `Logger#debug/error/info/success/warn`, `ConsoleInfo`, `BaseMethods`, `LoggerData`, `LoggerFormatter`.                               |
| `LoggerSaveData`          | `(context: { getFmtLog: <T>() => T } & BaseContext) => Return`                                                                      | The save-log-data function type, invoked with a `getFmtLog` accessor to retrieve the formatted log.                                      | Used by `Logger`'s internal `#saveFuntion` field and the `storage.save` option.                                                              |
| `BaseMethods`             | `Exclude<LoggerMethods, 'success'>`                                                                                                 | The base logger method names — the subset that maps 1:1 to a native `console` method.                                                    | Used to constrain `ConsoleInfo<Method>`.                                                                                                     |
| `ConsoleInfo`             | `Console[Method]`                                                                                                                   | The native `console` method invoked for a given base logger method.                                                                      | Used to type the `...data` parameters of `LoggerData` for `debug`/`error`/`info`/`warn`.                                                     |
| `GlobalConsole`           | `typeof console`                                                                                                                    | The type of the global `console` object.                                                                                                 | Used to define `BaseMethods`/`ConsoleInfo` and by the internal `baseHeaderLog`/`showMessage` console wrappers.                               |
| `LoggerOptions`           | `LoggerFunctionOptions<Return> \| LoggerFileOptions<Return>`                                                                        | The full `new Logger(options)` constructor options — either the function-based or file-based storage style.                              | Type of the `Logger` constructor's `options` parameter.                                                                                      |
| `LoggerFunctionOptions`   | `{ disableGlobalAssign?: boolean; storage?: { formatter?: Formatter } & SaveDataFunctionOptions<Return> \| false }`                 | `LoggerOptions`'s function-based-storage half — `storage.save` is a `SaveDataFunction`.                                                  | One of the two `Logger` constructor overloads; useful for annotating a custom-save-function config (docs style 1/6).                         |
| `LoggerFileOptions`       | `{ disableGlobalAssign?: boolean; storage?: { formatter?: Formatter } & SaveDataFileOptions \| false }`                             | `LoggerOptions`'s file-based-storage half — `storage.save` is a `SaveDataFile` config object.                                            | One of the two `Logger` constructor overloads; useful for annotating a file-storage config (docs style 2/3).                                 |
| `SaveDataFunctionOptions` | `{ save: SaveDataFunction<Return, BaseContext> }`                                                                                   | Wraps a custom `save` function as `storage`'s shape when using function-based storage.                                                   | The `storage` shape inside `LoggerFunctionOptions`.                                                                                          |
| `SaveDataFile`            | `{ folder?: string; expirationTime?: \`${number}d\` } & ({ useWorker?: false } \| { useWorker?: true; callback?: TaskCallback })`   | The file-storage config object: destination folder, expiration, and optional worker offload.                                             | Used by the built-in `defaultSaveData`/`baseSaveData` file storage, and as `SaveDataFileOptions.save`'s type.                                |
| `SaveDataFileOptions`     | `{ save?: SaveDataFile }`                                                                                                           | Wraps a `SaveDataFile` config as `storage`'s shape when using file-based storage.                                                        | The `storage` shape inside `LoggerFileOptions`.                                                                                              |

## Error types

Types describing serializable errors and the built-in HTTP error codes, exposed from `@zanix/utils/errors`.

| Type name            | Definition                                                                                                                                                                                                                                                                                                               | Description                                                                              | Used by                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `BaseSerializeError` | `Partial<{ name: string; message: string; stack: string; cause: BaseSerializeError }>`                                                                                                                                                                                                                                   | The base serializable error shape: `name`, `message`, `stack` and a recursive `cause`.   | Base constraint for `SerializeError`.                                                                           |
| `ErrorOptions`       | `{ message?: string; cause?: unknown; id?: string; code?: string; meta?: Record<string, unknown>; shouldLog?: boolean }`                                                                                                                                                                                                 | Error options used to construct and identify custom errors.                              | Used by `HttpError`, `ApplicationError`, `PermissionDenied`, `InternalError` (all in `modules/errors/main.ts`). |
| `HttpErrors`         | `'BAD_REQUEST' \| 'UNAUTHORIZED' \| 'FORBIDDEN' \| 'NOT_FOUND' \| 'INTERNAL_SERVER_ERROR' \| 'TOO_MANY_REQUESTS' \| 'METHOD_NOT_ALLOWED' \| 'CONFLICT' \| 'PAYLOAD_TOO_LARGE' \| 'UNSUPPORTED_MEDIA_TYPE' \| 'UNPROCESSABLE_ENTITY' \| 'NOT_IMPLEMENTED' \| 'BAD_GATEWAY' \| 'SERVICE_UNAVAILABLE' \| 'GATEWAY_TIMEOUT'` | The HTTP error codes commonly used in REST APIs, each mapping to a standard HTTP status. | Used by `HttpError.status.code` and the internal `httpStates` (`httpErrorStates`) map.                          |
| `SerializeError`     | `type SerializeError<T extends BaseSerializeError = BaseSerializeError> = T`                                                                                                                                                                                                                                             | A serializable error, defaulting to the base `{ message, stack, cause }` shape.          | Return type of `serializeError`/`serializeMultipleErrors`.                                                      |

## Worker types

Types for the one-time worker task system used by `WorkerManager` (`@zanix/utils/workers`) and by other library features that can optionally offload work (e.g. logger file storage).

| Type name              | Definition                                                              | Description                                                                | Used by                                                                                                               |
| ---------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `TaskCallback`         | `(response: TaskCallbackResponse) => void`                              | Callback invoked after a worker task is completed or when an error occurs. | Used by `WorkerManager#task`'s `onFinish` option and `SaveDataFile.callback`.                                         |
| `TaskCallbackResponse` | `{ response: any \| null; error: unknown \| null; messageId?: string }` | The result payload passed to a task's `onFinish` callback.                 | Built and passed by the internal worker `processor` (in `modules/workers/processor.ts`), consumed via `TaskCallback`. |
| `TaskFunction`         | `(...args: never[]) => unknown`                                         | A function that can be executed as a task inside a `WorkerManager` worker. | Used by `WorkerManager#task<T extends TaskFunction>`.                                                                 |

## Encryption & masking types

Types for the encryption and masking helpers exposed from `@zanix/utils/helpers` (AES, RSA, HMAC, SHA hashing, and reversible/irreversible text masking).

| Type name               | Definition                                                                | Description                                                                | Used by                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `AESLength`             | `128 \| 192 \| 256`                                                       | The supported AES key lengths, in bits.                                    | Used by `generateAESKey`.                                                                                           |
| `EncryptionLevel`       | `'low' \| 'medium' \| 'medium-high' \| 'high'`                            | The hashing strength level used for unidirectional encryption.             | Used by `generateHash`/`validateHash` to pick the SHA algorithm and iteration count for **unidirectional hashing**. |
| `HashAlgorithm`         | `'SHA-1' \| 'SHA-256' \| 'SHA-384' \| 'SHA-512'`                          | Supported cryptographic hash algorithms (the SHA family).                  | Used by `generateHash`, `validateHash`, `generateRSAKeys`, `signHMAC`/`verifyHMAC`, `ValidRSAKeysOptions`.          |
| `MaskingAlgorithms`     | `'xor' \| 'hard'`                                                         | The supported masking algorithms: reversible `xor` or irreversible `hard`. | Used by `MaskingOptions.algorithm` and `UnMaskingOptions.algorithm` (via `mask`/`unmask`).                          |
| `MaskingBaseOptions`    | `{ startAfter?: number \| string; endBefore?: number \| string }`         | Options controlling where the text masking process starts and stops.       | Base of `MaskingOptions`/`UnMaskingOptions`, used internally by `mask`/`unmask`.                                    |
| `MaskingOptions`        | `{ algorithm?: MaskingAlgorithms } & MaskingBaseOptions`                  | Options accepted by the `mask` function.                                   | Used by `mask`.                                                                                                     |
| `UnMaskingOptions`      | `{ algorithm?: Exclude<MaskingAlgorithms, 'hard'> } & MaskingBaseOptions` | Options accepted by the `unmask` function.                                 | Used by `unmask`.                                                                                                   |
| `ValidRSAKeysOptions`   | `{ algorithm?: 'RSA-OAEP' \| 'RSA-PSS'; hash?: T; modulusLength?: ... }`  | Options accepted when generating or using RSA keys.                        | Used by `generateRSAKeys`.                                                                                          |
| `ValidRSAModulusLength` | `1024 \| 2048 \| 3072 \| 4096`                                            | The supported RSA key modulus lengths, in bits.                            | Used by `ValidRSAKeysOptions.modulusLength`.                                                                        |

## Linting & formatting file-extension types

> **Moved**: the repository-bootstrapping types that used to live here
> (`BaseEditorHelperOptions`/`BaseGithubHelperOptions`/`Editors`/`HookOptions`/

> hook/workflow/editor-config helpers they described — both moved to `@zanix/cli`, which was their
> only real consumer. See [Helpers](./helpers.md) and `@zanix/cli`'s own `ENGINEERING.md` §5/§7.

| ---------------------- | ---------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| `LinterAvailableFiles` | `'ts' \| 'tsx' \| 'js' \| 'jsx'`         | File extensions the linter can be configured to check.    | General-purpose file-extension union; base of `FormatAvailableFiles`, consumed the same way as it.                                                                       |

## Zanix framework types

Types describing the recommended Zanix project/folder structure and the `Znx` global namespace,
exposed from `@zanix/utils/helpers`.

> **Note**: the _implementation_ that builds/consumes these shapes (`getZanixPaths`,
> `getAllZanixLibrariesInfo`, `ZanixTree`/`BaseZanixTree`, `getServerSrcTree` and its sibling
> per-project-type builders) moved to `@zanix/cli` — it was the only real consumer. These _types_
> stayed in `@zanix/utils/types` because they're shared vocabulary: `@zanix/cli`'s own generator
> commands (`ZanixFolderGenericTree`) and its moved tree-building code both depend on them. See
> [Helpers](./helpers.md) and `@zanix/cli`'s own `ENGINEERING.md` §5/§7.

| Type name                | Definition                                                                                                          | Description                                                                                                       | Used by                                                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `ZanixAppSrcTree`        | `ZanixBaseFolder<{ Components; Layout; Pages; resources: {...} }, 'noTemplates'>`                                   | Zanix App folder structure (`@experimental`).                                                                     | Used by `@zanix/cli`'s own `getAppSrcTree`, part of `ZanixSrcTreeMap['app']`.                                                               |
| `ZanixBaseFolder`        | `Omit<ZanixBaseFolderProps<S>, ...>`                                                                                | The recursive folder-tree shape shared by all Zanix folder structures.                                            | Used throughout `typings/zanix.ts` (every `Zanix*SrcTree`/`ZanixFolderTree`) and by `@zanix/cli`'s own `BaseZanixTree`/`ZanixTree` classes. |
| `ZanixBaseFolderProps`   | `{ readonly FOLDER: string; readonly NAME: string; templates: ZanixTemplatesRecord; subfolders: S }`                | The base fields present on every Zanix folder-tree node.                                                          | Base of `ZanixBaseFolder`.                                                                                                                  |
| `ZanixBaseLibraryInfo`   | `{ version: string }`                                                                                               | Basic identifying info for a Zanix library dependency.                                                            | Used by `ZanixLibraries` (one entry per `@zanix/*` package).                                                                                |
| `ZanixFolderGenericTree` | `Partial<ZanixBaseFolder<Record<string, Partial<ZanixBaseFolder>>>>`                                                | A generic folder structure modeling a file system where each folder can recursively contain subfolders and files. | Actively used by `@zanix/cli`'s own `zanix generate <artifact>` commands and its `createFilesAndFolders` primitive.                         |
| `ZanixFolderTree`        | `ZanixBaseFolder<ZanixProjectSrc<T> & { '.dist'; docs; src: ZanixBaseFolder<ZanixSrcTree<T> & {...}> }>`            | The complete Zanix project folder tree (root-level), parameterized by project type.                               | Return type of `@zanix/cli`'s own `getZanixPaths`; used by its `getZnxFolderTree`/`getCommonTree`.                                          |
| `ZanixGlobal`            | `interface { logger: DefaultLogger; onmessage?; postMessage?; Znx: {...} }`                                         | Global library type modules definition — the shape of the `globalThis`/`Znx` augmentation.                        | Used by the internal `Zanix` alias (`= ZanixGlobal['Znx']`) consumed by `setGlobalZnx`/`getGlobalZnx` (both still in `@zanix/utils`).       |

| `ZanixLibrarySrcTree`    | `ZanixBaseFolder<undefined>`                                                                                        | Zanix Library folder structure.                                                                                   | Used by `@zanix/cli`'s own `getLibrarySrcTree`, part of `ZanixSrcTreeMap['library']`.                                                       |
| `ZanixLocalContentProps` | `{ metaUrl: string; relativePath?: string }`                                                                        | Context passed to a template's `content` resolver function.                                                       | Used by `ZanixTemplatesRecord`'s per-template `content(local)` resolver, consumed by `@zanix/cli`'s own `ZanixTree`.                        |
| `ZanixProjects`          | `'library' \| 'server' \| 'app' \| 'app-server'`                                                                    | The available Zanix project types.                                                                                | Used by `@zanix/cli`'s own `getZanixPaths`, `ConfigFile.zanix.project`, `ZanixGlobal['Znx']['config'].project`.                             |
| `ZanixProjectsFull`      | `ZanixProjects \| 'all' \| undefined`                                                                               | `ZanixProjects` plus the `'all'` and `undefined` (common-structure) cases.                                        | Used by `@zanix/cli`'s own `getZanixPaths<T>`, `ZanixSrcTree<T>`, `ZanixProjectSrc<T>`.                                                     |
